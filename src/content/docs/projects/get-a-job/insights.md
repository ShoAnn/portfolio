## Challenges
- Outdated tutorials
- So many different pattern for each tutorial
- Unclear direction because of unspecified goals
- Having to remember so many design patterns

## Lessons Learned
- Need to set features for MVP at the beginning
- Need to have strong foundation first before learning new tools
- Need learn more about system design
- Need to learn more about UI/UX
- Need to learn more about testing (QA)
- No need to follow best practices at first
- Better to not follow complicated design patterns at first because you are still learning
