Teknologi
Frontend: Next.js 16, React 19, TypeScript
Styling: Tailwind CSS 4
UI/UX Library: Recharts (grafik), @dnd-kit/core (drag-and-drop)
Backend: Go 1.25, router net/http (standard library)
Data Access layer: sqlc (sql to go generator), pgx (DB driver), golang-migrate (migration tool)
Basis Data: PostgreSQL 18
Otentikasi: JWT (cookie HttpOnly), rotasi refresh token, bcrypt
Validasi: go-playground/validator (backend), Zod (frontend)
Pengujian: Vitest + Testing Library (frontend), Testify (backend)
Infrastruktur: Docker Compose, Air (live reload), Adminer (UI basis data)
Deployment: Sedang berlangsung
