## Front-end Library
- TypeScript

- React 19
- Recharts (grafik)
- @dnd-kit/core (drag-and-drop)

- Go 1.25, router net/http (standard library)

- pgx (DB driver)
- golang-migrate (migration tool)

- Zod (frontend)

- Vitest + Testing Library (frontend)
- Testify (backend)

- Docker Compose
- Air (Go live reload)
